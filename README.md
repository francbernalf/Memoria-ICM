Code from my undergraduate thesis in Mathematical Engineering (Universidad de Valparaíso, Chile, first semester of 2025), titled "Modelamiento estocástico del movimiento de larvas de loco y erizo rojo para evaluar el efecto de cambios en la salinidad del ambiente" *(Stochastic modeling of the movement of Chilean loco and red sea urchin larvae to assess the effect of changes in environmental salinity)*. The full thesis is available at the [Universidad de Valparaíso library](https://repositoriobibliotecas.uv.cl/handle/uvscl/17217).

## About the data

The original experimental data is not included for privacy reasons. `data/data_simulada.db` is a simulated SQLite database with the same structure, so the code can run end to end. Everything else is the original code from the thesis. Results obtained with the simulated data will not match those reported in the document.

## Structure

- `src/memoria_icm/`: data loading, trajectory variables, plotting, and the Ornstein–Uhlenbeck and CIR model functions
- `notebooks/`: main analyses (functional data analysis, ANOVA by salinity level, OU and CIR calibration)
  - `cerrados/`: earlier steps (database creation, exploratory analysis, time analysis)
  - `exploratorios/`: side explorations not included in the final thesis
- `resultados/`: figures generated by the notebooks

## Running it

```bash
git clone https://github.com/francbernalf/memoria-icm
cd memoria-icm
pip install -e .
```

Then open any notebook. Dependencies are listed in `pyproject.toml`.

Note: the code, comments and notebooks are written in Spanish.
